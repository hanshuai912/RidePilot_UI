# M01 · 我的

## 页面目标

用户从底部「我的」进入，查看并维护运动档案、目标、训练与饮食偏好，以及数据和隐私设置。

## 入口与返回

- 入口：底部「我的」；训练/饮食页面可深链到对应档案字段。
- 本页是一级页面。进入档案、目标、隐私和设置的二级页后，返回时保留滚动位置；编辑表单有未保存内容时需提供继续编辑、保留草稿或放弃。

## 信息层级

1. 第一眼：页面昵称、脱敏手机号与账号未验证状态、当前阶段、下一次测试、当前长期目标。
2. 继续下滑：身体与能力、训练时间、饮食偏好与禁忌、课程视图偏好。
3. 进一步下滑：AI 数据使用与授权、导出/删除数据路径、设备同步状态。

## 复用组件

`AppHeader`、`BottomTabBar`、`SurfaceCard`、`StatusIndicator`、`GoalTimeline`、`EmptyState`、`ConfirmSheet`。列表项与前三个页面使用相同圆角、间距、边框和箭头样式；不引入新的主色或导航结构。

## 关键交互

| 操作 | 系统反馈 | 去向 / 状态 |
|---|---|---|
| 点击骑行档案 | 查看页面昵称、脱敏手机号、验证状态、运动项目和训练经验 | 档案详情；昵称可编辑，手机号和验证状态只读 |
| 点击当前目标 | 查看长期目标、阶段路线、测试与能力趋势 | G01；修改目标先生成计划调整草稿 |
| 点击身体与能力 | 编辑可选身体数据、FTP/阈值心率、测试日期和来源 | 档案编辑；重要能力值改变时提示是否重新计算未来训练区间，进入预览和确认；历史记录不变 |
| 点击训练时间 | 编辑每周可用时段、休息日、单次最长时长与时区 | 档案编辑；若影响正式计划，生成待预览调整，不直接重排 |
| 点击饮食偏好与禁忌 | 编辑过敏原、禁忌与用餐习惯 | 饮食档案；对现有未来餐食重新校验，冲突需明确处理 |
| 点击课程显示偏好 | 在简洁/专业视图间切换 | 保存偏好；课程结构和训练草稿不变 |
| 点击隐私与授权 | 查看 AI 数据使用、权限和撤回入口 | 隐私设置 |
| 点击导出或删除数据 | 展示可导出范围、处理进度；删除需说明影响并二次确认 | 数据管理；不可把点击列表项当作删除确认 |
| 点击右上设置 | 账户、通知、单位和退出登录等设置 | 设置页 |

## 个人信息入口与返回

- 点击“我的”顶部个人卡片进入独立“个人信息”页；“我的资料”分组及“账户与页面昵称”“身体与能力”两个入口不再显示。FTP 与 COROS 沿用原入口。
- 个人信息页隐藏底部五栏导航，顶部左侧为 44 pt 触控区域的返回箭头图标，中间为 17 pt“个人信息”文字，两侧保留等宽区域，确保标题相对页面居中。
- 未修改或改回原值时，保存资料按钮置灰；有修改后启用，保存期间禁用编辑与返回。保存成功返回概览并刷新资料。
- 未保存返回时，弹出“有未保存的修改”，提供“继续编辑”和“放弃修改”；前者保留草稿，后者返回并恢复已保存信息。网络错误、校验失败和版本冲突保留当前输入。

## 骑行功率区间

- “我的”FTP 功率卡片仅展示标题、当前瓦数和箭头；未填写显示“去填写”，不再展示最近测量时间与录入方式。点击跳转独立“骑行功率区间”页。
- 个人信息与骑行功率区间共用固定顶部导航：左侧返回图标，17 pt 标题居中。底部香槟金保存按钮固定并避让安全区，仅中间内容滚动。
- FTP 输入使用石墨灰分组卡片，下方 7 区列表展示编号、名称、百分比和瓦数；瓦数使用等宽数字，区间之间使用轻分隔线，不增加彩虹配色。
- 输入有效的 50–800 W 整数后立即重新计算，非法或空输入展示“— W”，禁用保存；未修改/还原原值同样禁用。保存失败保留输入，未保存返回提供“继续编辑”“放弃修改”。
- 分界为 55/75/90/105/120/150% FTP；下一段整数瓦数从上一上限 +1 W 开始。Z7 使用 >150% 作为冲刺参考，并提示实际以个人短时最大功率为准。
- 已验证 390 与 320 宽浏览器：内容滚动后标题和保存按钮位置不变，页面无横向溢出。

## 出生日期抽屉

- 个人信息页通过带日历图标和下拉箭头的日期入口打开底部抽屉；关闭键盘，沿用石墨灰面板、香槟金主按钮与底部安全区。
- 年、月、日三列独立上下滚动，中间固定金色选中带。滚动中保持文字连续，停止后更新预览；运动期间禁用「确认日期」，避免提交旧日期。
- 点击某行也可将该值定位到中间。第一项和最后一项均可居中；小屏显示三行，常规屏显示五行，行高适应字体缩放且不小于 44 pt。
- 日期范围为 1900-01-01 至设备本地今天；切换年月自动处理月末及闰日，不能选择未来生日。
- 确认后仅填入资料草稿，仍需保存资料；取消、遮罩、下拉顶部手柄或系统返回均丢弃本次选择，再打开恢复草稿原值。字段可清空，保存期间禁用修改。

## 示例数据与一致性

- 页面与 T01/N01/A01 处于同一示例日期：**2026 年 10 月 8 日**。当前阶段 **有氧基础**、下一次测试 **10 月 21 日**与训练页一致。
- 长期目标「提升长距离骑行耐力」是本轮示例文案，不承诺特定日期或能力提升值；阶段位置不能解释成目标完成百分比。
- 示例档案的 **FTP 未录入**，课程强度可使用 RPE/通俗强度描述；不能推断出精确瓦数。训练历史为手动记录，不显示任何已连接设备。
- 示例饮食档案已确认「无已知过敏」，对应 N01；实际食材成分仍需核对。
- 页面主卡展示脱敏手机号和“未验证”状态，不展示完整手机号、密码或验证码。昵称仅用于页面展示，可重复且可清空；未填写时显示“骑行者”。
- 年龄段和性别进入身体与能力详情；性别可选，选择“不愿透露”不阻断基础功能，不据此推断训练能力或营养需求。

## 边界状态

| 状态 | 界面处理 |
|---|---|
| 首次使用 / 档案不完整 | 用「待完善」标出缺项，只要求生成基础计划所必需的信息；可选身体数值不强制填写 |
| 无 FTP / 无设备 | 明确「FTP 待录入」「自动同步暂未开放」；提供 RPE/时长训练与手动记录路径 |
| 无目标 | 当前目标卡显示创建目标入口，不制造阶段或测试日期 |
| 加载 / 离线 | 保留已知栏目和上次成功同步时间；错误时提供重试，不把旧数据当作最新状态 |
| 档案修改影响计划 | 显示影响范围和前后差异，校验并要求用户确认后应用；已完成训练事实不变 |
| 饮食禁忌变更 | 重新校验未来建议；命中禁忌的餐食不可无提示继续应用 |
| 时区变化 | 询问保留当地钟点还是绝对时间，再预览对计划和比赛日期的影响 |
| 隐私权限不足 | 说明受限信息和恢复授权方式；不泄露敏感字段 |
| 未保存编辑 | 返回提示继续编辑、保留草稿、放弃修改 |
| 大字体 / 小屏 | 列表副文案换行、行高自然增高；底部内容可滚动且不被导航栏遮挡 |

## 待确认

- 头像是否纳入一期；页面昵称已纳入用户信息字段，默认展示「骑行者」，不从手机号生成昵称。
- 数据导出格式、删除后的保留范围和处理时限，需按目标市场与实现方案确认。
- 通知与单位设置的最终入口结构；当前归入右上设置。

## 验收要点

- 五栏导航顺序固定，「我的」为金色选中态。
- 缺失 FTP、设备和身体资料如实显示，不伪造测量值或已连接状态。
- 修改 FTP、目标、训练时间或饮食禁忌不会悄悄覆盖正式训练/饮食计划。
- 简洁/专业视图切换只改变展示密度，不改课程数据。
- 隐私授权、导出和删除路径可找到；删除操作有明确后果和确认步骤。
- 用户信息接口只更新显式提交的允许字段；修改昵称不改变手机号、`user_id` 或已有训练数据。
- 所有可点击行至少约 44 pt 高；滚动内容和固定底栏尊重安全区。

## 心率区间与能力入口卡片

- “我的”新增统一“心率区间”卡片；详情称“乳酸阈心率”，不加运动类型前缀。最大心率为 5 区，储备心率为 5 区，乳酸阈心率为 7 区。
- 顶部使用三个完整宽度单选行，按需填写最大/静息/乳酸阈心率，下方即时显示区间。切换保留各类数值，保存类型和三个数值；未填写不展示示例心率。
- 详情复用固定左侧返回图标、17 pt 居中标题、底部固定保存按钮；有修改且合法才可保存，未保存离开确认、失败保留草稿。
- FTP 与心率卡片共用 18 pt 圆角石墨面板、16 pt 内边距、32 pt 暗金图标底、18 pt 线性图标及至少 72 pt 行高；标题 16 pt / 500，数值或操作文案 13 pt，辅助说明 12 pt。FTP 不展示最近测量时间或录入方式。
- 数值和区间使用等宽数字；沿用既有主题 tokens，390/320 宽均可滚动阅读，保持触控目标和字体缩放。
