# T05 · 调整训练（具体课程）

2026-11-12 用户要求重设计 WorkoutAdjustmentForm，并将生成操作移到标题右侧、精简文案，移除页面取消按钮。与 A03 的按范围调整入口区分，本页绑定一节已排定课程。

## 页面结构

- 入口：首页「调整这节训练」、课程详情调整入口。顶部居中「调整训练」，左返回，右侧单行金色「生成」，至少 44×44pt，无水平内边距。操作随标题固定，页面末尾没有生成或取消按钮。
- 正文：当前课程卡（真实标题、日期、已知时长、正式版本）→ 六个两列原因单选 → 两项范围单选 → 选填多行说明 → 草稿确认提示与真实错误。
- 原因包括时间不足、疲劳或睡眠差、天气影响、临时有事、课程太难、之前漏练。选中以金色边框、底色与勾选表达，触控至少 48pt。用户选择原因，不代表系统健康判断。
- 范围为仅此课程、联动后续课程。仅此课程默认；联动时显示起止日期及已记录课程保留说明，阶段、测试、补给需另行确认。
- 20pt 横向留白、24pt 分区间距、20pt 分区标题、16pt 正文和13pt 辅助，复用黑金 Token。输入至少 120pt 高、最多 200 字，有字数提示。窄屏自然换行。

## 日期选择

实际 App 复用统一年／月／日滚动选择器，最早为当前课程日期，最晚为其后第83天（含首日共84天），默认结束日期为第7天。确认才提交到表单，取消保留原值。切换范围保留日期、原因与备注。HTML 日期入口链接本说明，不模拟日期保存。

## 生成与状态

- 单节点击顶部生成才请求草稿；联动先展示起止日期范围确认，选择「返回修改」保留表单且不生成，「确认范围并生成草稿」才请求。后续进入相应草稿差异预览，校验、明确确认后才正式应用。
- 生成中右侧显示加载且禁用，范围、原因、日期、备注和顶部返回同时锁定。保留既有长任务取消能力；移除的是普通页面取消按钮。
- 生成失败保留表单，可再次从顶部生成。返回沿来源导航并保留已有未保存确认；预览返回保留输入。
- 加载、未登录、读取失败、FTP 缺失、课程已记录或不可编辑时不展示生成入口；错误继续提供重试或完善资料。
- HTML 使用合成数据，仅演示选择与布局，生成链接说明，不产生业务写入。真实验证及真机限制见主仓库 docs/features/workout-actions.md 同日章节。
