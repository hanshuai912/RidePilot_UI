# N01 · 饮食首页

## 页面目标

用户从底部「饮食」进入，快速知道当天建议吃什么，以及如何围绕已安排的骑行做前、中、后补给；需要时调整餐食或补给。

## 入口与返回

- 入口：底部「饮食」；首页的今日饮食/补给卡；训练课程的关联补给入口。
- 本页是一级页面，切换底部栏目时保留选中日期。餐食详情、补给编辑和饮食档案是二级页，返回时保留日期与滚动位置。

## 信息层级

1. 第一眼：日期、关联的正式训练、早餐/午餐/晚餐的建议食物与替换入口。
2. 继续下滑：训练前中后补给建议、饮食禁忌状态。
3. 进一步展开：餐食食材、分量、用餐时间、可核实的营养信息及来源；本页不放无来源的热量合计。

## 复用组件

`AppHeader`、`BottomTabBar`、`SurfaceCard`、`MealCard`、`StatusIndicator`、`SecondaryButton`。训练补给使用既有卡片容器和阶段式信息层级；食物缩略图只承担识别作用，不作为营养含量证据。

## 关键交互

| 操作 | 系统反馈 | 去向 / 状态 |
|---|---|---|
| 选择日期 | 同步加载该日正式训练、餐食和补给；空日期显示明确空态 | 留在 N01 |
| 点击今日训练条 | 查看该训练的目标与结构 | T02 |
| 查看并调整补给 | 修改前/中/后安排和时间；先保存草稿，再展示训练与营养影响 | N02 → 差异预览 → 校验 → 确认应用 |
| 点击餐食卡 | 查看食材、分量、用餐时间、禁忌与可用营养数据 | N02 |
| 点击「替换」 | 先选择不喜欢、买不到、外出就餐或准备时间不足；返回 1–3 个可比较选项 | N02，生成替换草稿；核对禁忌、预览变化并确认后应用 |
| 点击右上档案 | 查看或修改偏好、过敏原、禁忌 | M01 饮食档案；更新后重新校验未来建议 |
| 训练计划变化 | 展示「补给建议待确认」而非直接改写正式饮食计划 | 进入联动差异预览，可独立决定是否应用营养变更 |

## 示例数据与依据

- 画面为 **2026 年 10 月 8 日、周四**，与 T01 示例同日；正式训练为 **60 分钟耐力骑行**。全部餐食均标为设计示例/建议，未记录为实际进食。
- 本示例用户已确认「无已知食物过敏」。产品实际显示「已按档案筛选」前，必须有对应档案状态及食材/成分数据；缺失时改为「饮食禁忌待确认」。
- 三餐示例：早餐香蕉蓝莓燕麦碗；午餐鸡胸藜麦蔬菜餐；晚餐三文鱼烤蔬菜餐，主食另配。配图为氛围示意，不能推断份量与营养值。
- 60 分钟耐力骑行的补给文字采用保守、一般性的建议，不声称人人必须摄入固定碳水或水量。具体方案需结合用餐时点、天气、个人体验与资料质量。
- [餐食图片素材](../assets/meals-triptych.png)为本轮生成的摄影素材；无文字、无营养标签。

## 边界状态

| 状态 | 界面处理 |
|---|---|
| 首次使用 / 无饮食计划 | 显示「尚无今日饮食建议」，引导先确认饮食偏好与过敏/禁忌；不得套用示例餐食 |
| 无今日训练 | 将补给卡替换为「今天无训练安排」及常规用餐说明；不保留运动补给处方 |
| 档案不足 / 过敏信息未知 | 显示明显待确认提示，餐食只作为待核实建议；成分不全时阻止自动确认或应用 |
| 加载 | 日期保留，训练条、补给卡与三餐卡使用等尺寸骨架，不闪现旧日期数据 |
| 离线 / 获取失败 | 显示失败原因及「重试」；若展示缓存内容，标明最后更新时间和未同步状态 |
| 替换生成中 | 显示「正在核对食材与禁忌」等阶段反馈，可返回当前餐食而不丢失草稿 |
| 替换冲突 / 禁忌命中 | 标出具体食材与原因，阻止应用；提供符合限制的替代选项 |
| 训练变更草稿待应用 | 正式饮食计划保持原状；单独显示「训练补给可能变化，待预览」入口 |
| 未保存草稿 | 返回时提供「继续编辑」「保留草稿」「放弃修改」 |
| 大字体 / 小屏 | 卡片自然增高，餐食名称换行，底部导航遵守安全区；图片不挤占必要文字 |

## 待确认

- 正式食物成分库、菜谱来源及使用许可；确认前不显示精确营养值。
- 是否提供「已吃 / 部分吃 / 未吃」的日常记录快捷按钮；当前从餐食详情进入记录。
- 训练补给是否与餐食计划共用版本，或拥有独立版本；当前按 PRD 的饮食计划版本管理。

## 验收要点

- 底部固定五项且顺序与 H01/T01 一致，饮食项为金色选中态。
- 训练数据与 T01 同源；训练改为休息后，补给只产生建议草稿，不覆盖正式计划和实际进食记录。
- 替换餐食保留已确认的过敏原与禁忌约束；成分未知时有可读提醒并阻止无提示应用。
- 建议/记录/估算状态清楚区分；无可靠来源不出现精确热量或宏量营养素数值。
- 所有点击目标至少约 44 × 44 pt，文字缩放与滚动不会被底部栏遮挡。
